# Ceview_SBERT Tourism Classification Model

This project contains the source code, training notebooks, and documentation for a multi-class tourism business classification model.

## Overview
The model is built using **PyTorch** and takes a business description, unique value proposition, and a list of services, and predicts which of the 7 tourism categories the business falls into. It supports multi-label classification using a threshold.

## Getting Started
See `docs/model.md` for the core model contract.
See `docs/training.md` for how to train the model using Google Colab and details on **dataset preparation and class imbalance strategies**.
